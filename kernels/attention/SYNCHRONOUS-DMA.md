# Synchronous DMA attention variant

`gen.py --variant synchronous-dma` explicitly selects a conservative dimension-64 attention schedule. The existing `v2` default, default assembly modules, and kit dispatch remain unchanged. This variant inserts `dma.wait ch0` or `dma.wait ch1` immediately after each transfer and a scalar `nop` before the terminal `ecall`. It completes DMA before subsequent vector accesses and makes the final `delay 128` retire before halt. It preserves every original instruction and all operand layouts, masks, scaling, and arithmetic.

`atlas_attention_sync.synchronous_dma(source)` requires the exact original v2 halt tail and known channel syntax. Changed tails, unsupported channels, and applying the variant twice fail closed. Wide-head generators reject this variant. The existing v2 configuration validates geometry and the normal compiler checks still apply; selecting this variant never downgrades the required verification tier.

`coverage.bench_model.build` accepts `attention_operands=(Q,K,V)` containing finite FP32 arrays with shapes `[query_heads,rows,64]`, `[kv_heads,keys,64]`, and `[kv_heads,keys,64]`. These pass through the shared BF16 staging and FP8 quantization policy. `attention_mask_values` supplies a boolean `[rows,keys]` mask for arbitrary masking, with at least one visible key per query. Select this schedule with `params.variant="synchronous-dma"`. Omitted operands and variant preserve the existing synthetic benchmark path.

The Multi-Task DiT qualification uses complete 197x197 vision attention with 72 heads after flattening six image batches, complete 77x77 text attention with eight heads and its actual causal/padding mask, and complete 32x32 denoiser attention with eight heads. [The campaign report](../../coverage/ROOFLINE-MTDIT.md) records the measured gates and remaining limits. This variant trades overlap for a provable schedule; it is not claimed to improve performance.

`tests/test_attention_sync.py` checks the exact transfer and halt changes, fail-closed controls, assembled default-word equality, and the additional instruction count. `coverage/tests/test_bench_model.py` checks supplied real-boundary staging, actual arbitrary masks, and invalid inputs. Qualification separately requires compiler stream and timing verification, assembler equality, exact timed-versus-functional outputs, and official-versus-RTL output and cycle agreement. Attention has no independent target-arithmetic golden, and no whole-model exactness or accuracy claim follows from these checks.
