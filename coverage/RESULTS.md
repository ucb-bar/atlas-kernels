# Kernel bench results

Generated by `python3 lib/kernel_bench.py --model-root NPU_MODEL --out OUT --timed` (10,675 CPU-seconds in all, 1,722 for the longest case, so 13 workers finish in about 30 minutes; `--report OUT` rewrites the tables from saved results). Inputs are seeded synthetic tensors at the real model shape; outputs run on npu_model 47b8599 with numerics="rtl". Bit-exact compares the output bytes with the lib/golden Atlas-arithmetic reference where one exists. Cosine and rel-err (||y - ref|| / ||ref||) compare the decoded output with the FP32 PyTorch reference on the unquantized inputs, so they include FP8 input quantization. Model cycles are npu_model Core cycle-model counts, not RTL cycles. Timed equals functional compares the timed and functional output bytes; either a golden mismatch or a timed/functional mismatch fails the command.

Cases without an independent golden: `attention/sv-prefix-arbitrary`, `attention/tl-prefill-causal`, `epilogue/tl-prefill-gate-silu`, `epilogue/tl-prefill-up-mul-fp8`, `rmsnorm/tl-decode-norm`, `rmsnorm/tl-prefill-norm`, `smol_fusion/sv-vision-fc1-bias-gelu`.
