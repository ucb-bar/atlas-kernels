# Retained benchmark evidence

Full generated benchmark JSON belongs in ignored output directories. The [TinyLlama manifest](examples/tinyllama/MODEL-BENCH.artifact.json) and [SmolVLA manifest](examples/smolvla/MODEL-BENCH.artifact.json) record its exact byte length, SHA-256, historical commit, and Git blob. The compact summaries alongside them preserve every report measurement at its original precision, including all 54 launch rows, counts, functional and timed durations, instruction words, numerical comparisons, and compiler tiers. The existing model tables remain the readable results.

## Recover and regenerate retained reports

From a normal clone of atlas-kernels, run:

```sh
make evidence
```

The target reads the pinned historical blobs from the clone's object database, verifies both full JSON and compact-summary hashes, checks that every compact measurement agrees with the full artifact, and writes `out/evidence/<model>/MODEL-BENCH.json` and `MODEL-BENCH.md`. The [SmolVLA projection](smol-projection-results.json) and [TinyLlama fused](tiny-fused-results.json) manifests also retain per-shape measurements and receipt digests; their complete receipts, including compiler joins, traces, and tool identities, recover to `out/evidence/variants/`. Recovery verifies those summaries against the full receipts. It runs no simulation and needs only Python 3 and Git. `OUT=...` selects another output root. Existing full JSON with different bytes is refused. Full receipts retain historical commands, diagnostics, compiler identities, machine paths, and SmolVLA's failed-original/retry provenance.

The model-bench source commit is `b860a6d85dfcfae27a1dce3f8b1c5e739d237f4b`; the variant source commit is `dcad2a317550d3b5a1d057c63ad1e5c2a491c3d9`. Both remain ancestors. A normal clone carries their objects. Shallow clones must fetch both before recovery:

```sh
git fetch origin b860a6d85dfcfae27a1dce3f8b1c5e739d237f4b dcad2a317550d3b5a1d057c63ad1e5c2a491c3d9
make evidence
```

Recovery does not need the original work-area paths. Keeping this history reachable is the durable evidence source; a squashed or history-filtered distribution must retain the commit or distribute the exact hash-checked artifacts separately. No public artifact upload is asserted here.

## Run fresh measurements

The existing benchmark target regenerates full results with explicitly provisioned model and compiler dependencies:

```sh
make bench-model MODEL=tinyllama OUT=out/bench/tinyllama \
  NPU_MODEL="$NPU_MODEL" MODEL_PYTHON="$MODEL_PYTHON" \
  ATLAS_MLIR_BIN="$ATLAS_MLIR_BIN" WORKERS=4
```

Repeat with `MODEL=smolvla` and `OUT=out/bench/smolvla`. Fresh execution measures the selected checkout. It does not recreate the historical source revisions merely by using the retained launch counts. The original run commands and configuration are preserved in the recovered JSON; reproducing those exact measurements requires the recorded kernel, compiler, and model revisions. The [roofline after opt-in variants](ROOFLINE-AFTER.md#reproduction-scope), [Qwen launch roofline](ROOFLINE-QWEN.md#method-evidence-and-limits), and [initial ResNet50 roofline](ROOFLINE-RESNET50.md#method-evidence-and-limits) have their own historical input requirements and are not regenerated by `make evidence`. [Artifact identifiers](ROOFLINE-MORE.artifacts.json) authenticate the retained Qwen and ResNet50 source reports and receipts; those full analysis artifacts are not shipped here.

Export fixtures, placement tables, compact RTL evidence, and the compact SmolVLA fusion receipt stay committed.
